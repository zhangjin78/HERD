# HERDOS 伽马数据分析：第一阶段——数据特征与分布

## 1. 当前范围

本阶段只回答三个基础问题：

1. 这批 ROOT 数据包含哪些可用于分析的事件级和晶体级信息；
2. 固定 1 GeV、垂直入射 gamma 在 v2025a 几何中的响应呈现什么分布；
3. 数据质量、样本选择和几何效应是否足以支持后续重建研究。

后续研究可分为：

1. 数据特征与分布（当前阶段）；
2. 传统方法重建 gamma；
3. 机器学习方法重建 gamma。

宏中包含的“总沉积能量单常数标定”仅作为独立测试集上的健康检查，不视为第二阶段的正式重建结果。

## 2. 数据集

- 样本：`gamma1GeV_v2025a_prod04`
- 几何：`v2025a/v2025a-scdX.xml`
- 入射：1 GeV gamma，`vertical-5x5`
- 总事件数：200,000
- 输入文件：4 个，每个 50,000 事件
- 分组原则：
  - 文件 0、1：预留训练/标定样本；
  - 文件 2：预留验证样本；
  - 文件 3：预留独立测试样本。

必须按文件保留这种划分，不能先混合事件再随机切分，否则同一生产子作业的条件可能同时进入训练和测试样本。

## 3. 已提取的特征

事件级 CSV 每行对应一个事例，包含：

| 类型 | 字段 | 含义与单位 |
|---|---|---|
| 标识 | `event`, `split` | 全局事件号、输入文件编号 |
| 真值 | `true_energy_GeV` | 初级 gamma 真能量，GeV |
| 转换状态 | `converted`, `unconverted_final` | 是否记录到初级 gamma 的首次对转换、是否记录到未转换 gamma 的最终状态 |
| 转换顶点 | `conv_x_cm`, `conv_y_cm`, `conv_z_cm` | 初级 gamma 第一次对转换位置，cm |
| CALO 总量 | `calo_edep_GeV` | 所有 CALO hit 的沉积能量和，GeV |
| 稀疏度 | `n_cells`, `n_cells_1MeV`, `n_cells_20MeV` | 有沉积、超过 1 MeV、超过 20 MeV 的晶体数 |
| 簇射位置 | `centroid_ix`, `centroid_iy`, `centroid_iz` | 以沉积能量加权的晶体索引重心 |
| 簇射形状 | `transverse_rms_cells`, `longitudinal_rms_layers` | 横向宽度（晶体索引单位）、纵向宽度（层索引单位） |
| 局域性 | `max_cell_fraction` | 单个最高能晶体占总沉积能量的比例 |
| 对转换真值 | `pair_energy_share`, `pair_opening_deg` | 正负电子能量共享和张角 |

注意：本版本 ROOT 文件里的 `calohits.pos` 无有效坐标，因此 CALO 位置和宽度使用 `ix/iy/iz` 晶体索引，不能解释成厘米。

## 4. 第一批统计结果

| 量 | 结果 |
|---|---:|
| 总事件数 | 200,000 |
| 记录到初级 gamma 首次对转换 | 163,354（81.677%） |
| 记录到未转换 gamma 最终状态 | 36,646（18.323%） |
| CALO 总沉积为零 | 36,340（18.170%） |
| 未转换但 CALO 非零 | 773（0.3865%） |
| 已转换但 CALO 零沉积 | 467（0.2335%） |
| 已转换样本 CALO 平均沉积能量 | 0.8968 GeV |
| 已转换样本 CALO 沉积能量 RMS | 0.1962 GeV |
| 每事例平均 `Ecell > 1 MeV` 晶体数 | 51.29 |
| 平均横向宽度 | 0.976 个晶体索引单位 |
| 平均纵向宽度 | 2.186 个层索引单位 |
| 首次对转换 z 坐标平均值 | 0.704 cm |

总零沉积数同时包含已转换和未转换事例，不能直接用两个总数相减。逐事例交叉分类后发现：

- 36,646 个未转换事例中，35,873 个 CALO 零沉积，773 个 CALO 非零沉积；
- 163,354 个已转换事例中，467 个 CALO 零沉积。

因此，不能把“未记录到首次对转换”等同于“CALO 完全无信号”。未发生 pair conversion 的 gamma 仍可能通过康普顿散射等其他过程留下沉积；具体过程需要回到 ROOT 中检查初级 gamma 的轨迹终点、次级粒子及可用的过程标识，不能仅凭当前事件级 CSV 下结论。

## 5. 当前图形反映的物理与几何信息

1. `01_calo_edep_converted`：主体接近 1 GeV，但有明显低能长尾。低能尾可能来自早期相互作用、横向或纵向泄漏、非完全包容，以及当前事件选择。
2. `04_hit_cell_multiplicity`：主要分布集中在约 40–70 个超过 1 MeV 的晶体，说明单个簇射天然适合表示为稀疏三维晶体图。
3. `06_edep_vs_conversion_z`：转换位置呈明显分段和空白区，反映几何材料层和空隙；沉积能量也随转换深度变化。这是后续重建必须控制的重要变量。
4. `07_shower_centroid_xy`：簇射重心集中在入射区域附近，和 `vertical-5x5` 的窄入射面相符。当前样本不能代表全量能器位置响应。
5. `09_longitudinal_profile`：能量主要集中在有限的 CALO 层，并在后部附近达到峰值；后续应结合真实几何层序确认 `iz` 的方向和边界含义。

## 6. 第一阶段还应补充的检查

在进入正式重建前，建议继续完成：

1. 将 converted / unconverted / zero-deposit 三类分开比较；
2. 专门检查 773 个“未转换但 CALO 非零”的事例和 467 个“已转换但 CALO 零沉积”的事例；
3. 按 `conv_z` 区间画 `Edep`、晶体数和簇射宽度；
4. 检查低能尾事例在转换位置、重心和边界距离上的分布；
5. 建立晶体占据率图和每层能量分数；
6. 确认 `ix/iy/iz` 与 v2025a 几何中实际晶体和层的映射；
7. 对四个子作业分别画关键分布，排除作业间漂移；
8. 对 50 MeV–20 GeV 样本沿用相同字段和按作业划分原则。

## 7. 对课题可行性的谨慎结论

这批数据已经证明：

- ROOT 中能够获得三维晶体能量、簇射形状和首次对转换真值；
- 单能样本统计量足以调试分析链、检查几何效应并建立基准变量；
- 数据可自然组织为稀疏三维输入，同时具备能量、转换位置和拓扑标签。

这批数据尚不能证明：

- gamma 能量重建的线性、偏差和分辨率随能量的表现；
- 机器学习优于传统方法；
- 模拟性能能够直接代表真实探测器性能。

原因是当前只有 1 GeV、固定入射区域，且使用的是模拟 hit 级能量沉积，尚未包含完整数字化、噪声、阈值和真实标定效应。正式能量重建结论需要使用 50 MeV–20 GeV 样本，并在独立测试集上与传统基线公平比较。
