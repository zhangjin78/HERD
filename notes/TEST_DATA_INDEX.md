# HERDOS 测试数据索引

整理日期：2026-07-30

本目录只保存开发、功能验证和性能测试数据，不应与正式物理生产样本合并。

## manual/v2025a-initial

早期手动运行样本，包括几何、可视化以及 gamma 首次对转换 MC truth 的逐步验证。

## benchmarks

固定参数的运行时间、内存和文件大小压力测试。

## batch

批处理子作业脚本的边界条件验证。

## v2025a

未转换初级 gamma 终态功能的固定 seed 验证。

## condor-validation

- `prod01`：带 `-gwn HERD` 的排队测试，没有生成 ROOT 文件；
- `prod02`：普通计算池提交验证，1000事例，不含未转换 gamma 终态；
- `prod03`：新 MC truth 功能验证，1000事例，包含792个首次对转换和208个未转换终态。

这些名称保留历史 tag，但分类均为测试数据。
